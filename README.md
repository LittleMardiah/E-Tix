# E-Tix Flash

E-Tix Flash adalah platform smart ticketing untuk portfolio project. Sistem ini dibangun sebagai monorepo yang terpisah menjadi backend (Go) dan frontend (Next.js 14 PWA).

## Status

FASE 0 - Foundation Setup (In Progress)

## Tech Stack

- Backend: Go (Modular Monolith, Clean Architecture)
- Frontend: Next.js 14 App Router, TypeScript, Tailwind CSS, PWA
- Database: PostgreSQL
- Cache: Redis
- Message Broker: RabbitMQ
- Deployment: Render, Vercel, Supabase, Upstash, CloudAMQP

## Struktur Proyek

- `backend/` - Aplikasi backend Go
- `frontend/` - Aplikasi frontend Next.js PWA
- `docs/` - Dokumentasi proyek

## Dokumentasi

Lihat folder `docs/` untuk dokumentasi lengkap seperti ROADMAP, TEAM_CONTRACT, dan spesifikasi teknis.
