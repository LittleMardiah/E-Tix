================================================================================
📌 OVERVIEW
================================================================================

Dokumen ini berisi **wireframe (blueprint UI)** untuk E-Tix Flash — platform tiket pintar dengan 4 user roles:

- 🧑 **Customer (Fans)** — Membeli tiket, split-pay, resale, masuk venue.
- 🎪 **Event Organizer (EO)** — Mengelola event, dashboard, analytics.
- 🚪 **Gate Staff** — Scan QR/PIN validasi tiket.
- 👨‍💼 **Admin** — Reconciliation, emergency tools, audit.

**Design Principles:**
- ✅ Mobile-first (320px - 768px)
- ✅ Web responsive (Desktop 1024px+)
- ✅ Accessibility (WCAG 2.1 Level AA)
- ✅ Dark mode support (optional)
- ✅ 100% SYNCHRONIZED WITH BACKEND — all screens map to PRD, DB, LOGIC FLOW
